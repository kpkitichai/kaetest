# บัญชีปลาใหญ่ (Big Catch Ledger)

Web app สำหรับจด **เฉพาะรายจ่ายพิเศษ** ที่เพิ่มขึ้นมาจากปกติในแต่ละเดือน เช่น ทำฟัน ซ่อมแอร์ ซองงานแต่ง
รายจ่ายเล็กๆ ประจำวันไม่ต้องจด ("ปลาตัวเล็ก ปล่อยคืนทะเล")

- ตั้ง **ค่าใช้จ่ายปกติต่อเดือน** และ **ยอดขั้นต่ำ** ที่จะนับเป็นรายจ่ายพิเศษ (ปุ่ม ⚙️ ตั้งค่าร้าน)
- แต่ละรายการเป็นจานซูชิบนสายพาน สีจานบอกขนาดเทียบกับค่าใช้จ่ายปกติ: ปลาทู < 5%, แซลมอน < 15%, ทูน่า < 30%, ฉลามยักษ์ ≥ 30%
- สรุปยอดรายเดือน, เทียบเดือนก่อน, กราฟย้อนหลัง 6 เดือน

## Run

```sh
go run .            # http://localhost:8080
go test ./...
```

Environment: `PORT` (default `8080`), `DATA_FILE` (default `data.json`)
